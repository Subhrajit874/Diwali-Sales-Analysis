# Diwali Sales Data Analysis

## Overview
Performed Exploratory Data Analysis (EDA) on a Diwali Sales dataset to understand customer purchasing behavior and identify business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Female customers contributed more to total sales.
- The 26–35 age group generated the highest revenue.
- Unmarried customers accounted for a significant share of purchases.
- Identified top-performing states and product categories.
